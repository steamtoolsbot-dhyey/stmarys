# St. Mary's School Gondal - Official Web Portal

A high-performance modern web application for **St. Mary's School, Gondal**, built with React 18, Vite, and Tailwind CSS.

## 🚀 Features

- **Dynamic Theme Engine**: 6 hand-crafted academic themes (Oxford Royal, Nordic Sage, Cambridge Crimson, Riviera Cobalt, Warm Cashmere, Elysian Platinum) with instant live preview.
- **Scroll & Pop Micro-Animations**: Hardware-accelerated entrance effects powered by `IntersectionObserver`.
- **Comprehensive Leadership & Faculty Directory**: Full staff listings with dedicated Principal and Vice Principal spotlight.
- **Academics & Campus Showcase**: Curriculum pathways, kindergarten facilities, science labs, computer suites, and sports grounds.
- **News & Official Circulars**: Dynamic announcements and admission notices.
- **Interactive Modals & Galleries**: Full-fidelity image lightbox previews.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Bundler**: Vite 5
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Icons**: Lucide React
- **Deployment**: Vercel

## 📦 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build

# Preview build
npm run preview
```

## 🌐 Deploy to Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Root Directory: `./`
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
